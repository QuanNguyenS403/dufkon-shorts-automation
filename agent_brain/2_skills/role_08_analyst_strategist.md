# Role 08: Phân tích & Chiến lược (Analyst & Strategist)

- **Inputs**: `data/dufkon.db` (`metric_snapshots`, `episodes`, `publications`), `3_case_bank/`, `4_learned_rules/`.
- **Responsibilities**:
  1. Capture metric snapshots at **24h, 72h, and 7d** post-publish; record `NA` for missing metrics and compare only same-age episodes.
  2. Track `presenter_layout`, `hook_pattern`, `duration_s`, and `views` / `likes` / `comments`.
  3. Run the **Weekly Reflection Loop** every Sunday to update `4_learned_rules/weekly_reflections.md` and `4_learned_rules/do_not_repeat.yaml`.
  4. Report 3 weekly decisions to the channel owner: winning series/format to scale, biggest drop-off bottleneck, and any budget/scope change needed.
